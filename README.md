# Rizoma Móvil

Proyecto de mensajería P2P y anónima sobre la red Tor para dispositivos móviles, basado en la lógica criptográfica de **Rizoma** y el modelo descentralizado de **Briar**.

---

## 📱 Proyecto Android Studio

El proyecto para Android Studio se encuentra en la subcarpeta:
👉 **`RizomaMovilApp/`**

### Instrucciones para Android Studio:
1. Abre Android Studio.
2. Selecciona **File > Open** y elige la carpeta:
   `rizomaMovil/RizomaMovilApp`
3. Deja que Gradle sincronice automáticamente y ejecuta en tu emulador o dispositivo Android.

Consulta la guía detallada en [`RizomaMovilApp/README.md`](RizomaMovilApp/README.md).
